# План: Додати підтримку PDF у OCR Processor

## Мета
Додати можливість завантажувати PDF-файли в OCR Processor. PDF складається зі сторінок-зображень (скановані документи), кожна сторінка конвертується в зображення та обробляється через наявний OCR-пайплайн.

## Залежності
`PyMuPDF` (`fitz`) уже є в `requirements.txt` — нових залежностей не потрібно.
Функція `pdf_page_to_image` уже існує в `blueprints/doc_generator/parsers/ocr.py:50` — використати схожий підхід, але реалізувати безпосередньо в `ocr_engine.py`, оскільки OCREngine працює з OpenCV/numpy, а не PIL.

## Крок 1: `ocr_engine.py` — Додати методи для роботи з PDF

### 1.1. Додати імпорт `fitz` на початку файлу

```python
try:
    import fitz  # PyMuPDF
    PYMUPDF_AVAILABLE = True
except ImportError:
    PYMUPDF_AVAILABLE = False
```

### 1.2. Додати метод `pdf_page_to_numpy(self, doc, page_num, dpi=300)`
- Конвертує PDF сторінку в numpy array (OpenCV BGR/Grayscale)
- Використовує `fitz.Matrix(dpi/72, dpi/72)` для рендеру
- Повертає grayscale numpy array (`cv2.cvtColor(img, cv2.COLOR_RGB2GRAY)`)

### 1.3. Додати метод `extract_from_pdf(self, pdf_path, include_handwritten=True, confidence_threshold=0.3)`
- Відкриває PDF через `fitz.open(pdf_path)`
- Ітерує по всіх сторінках
- Для кожної сторінки:
  - Конвертує в numpy image
  - Запускає `extract_printed_text()` (або `extract_all_text` на рівні окремої сторінки)
- Агрегує результат: друкований текст по сторінках, рукописний теж
- Додає в логи номер сторінки та кількість символів

### 1.4. Модифікувати `extract_all_text(self, image_path, ...)`
- На початку перевіряти розширення файлу: якщо `.pdf` — викликати `extract_from_pdf()`
- Інакше — працювати як зараз (для зображень)

## Перевірка

1. Завантажити PDF у формі — має пройти валідацію
2. Обробити PDF — кожна сторінка має бути розпізнана
3. Текст з усіх сторінок має бути об'єднаний у фінальний результат
