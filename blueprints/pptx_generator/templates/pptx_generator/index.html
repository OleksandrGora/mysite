Генератор PowerPoint презентацій

На головну

Введіть JSON даних

Інструкція

Введіть JSON масив об'єктів, де кожен об'єкт представляє один слайд презентації.

Обов'язкові поля:

  • title - назва слайду
  • body - основний текст слайду

Опціональні поля:

  • image_description - опис ілюстрації для генерації (поки що створює placeholder)

Приклад JSON:

[ { "title": "Вступ", "body": "Це перший слайд із текстом.", "image_description": "Схема процесу з трьома кроками" }, { "title": "Основна частина", "body": "Тут можна додати опис проекту." }, { "title": "Висновки", "body": "Фінальний слайд презентації." } ]
